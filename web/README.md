# Frontend

This folder is reserved for the frontend application.

## Future Implementation

The frontend can be built using:
- React / Next.js
- Vue.js / Nuxt.js
- Angular
- Blazor (if using .NET for frontend)
- Or any other frontend framework of choice

## API Integration

The frontend will communicate with the backend API located in the `../backend` folder.

Base API URL: `https://localhost:5001` (development)
API Documentation: `https://localhost:5001/swagger`
